# Артемида-2: Симуляция траектории полёта

Проект для симуляции полета корабля «Орион» к Луне и обратно - миссия Artemis 2. Теперь весь проект, и математика, и графический интерфейс, написан полностью на C++ с использованием фреймворка Qt5.

# TL;DR
Вот основные компоненты системы:
* **Физический движок (C++):** Считает гравитацию Земли и Луны, интегрирует методом Рунге-Кутты 4. Реализовано в `physics.cpp`.
* **Парсинг и симуляция (C++):** Читает реальные данные NASA Horizons из txt, ищет пик скорости, чтобы понять когда выключились двигатели (TLI), и крутит главный цикл. Это в `simulation_window.cpp`.
* **Визуализация (C++ / Qt5):** Отрисовка планет, траекторий и панели с телеметрией в реальном времени с помощью `QGraphicsScene`.
* **Тесты (C++):** Добавил юнит-тесты на `Boost.Test` для проверки математики и физики.

## Архитектура и стек технологий
* **Язык:** C++17
* **Графика:** Qt5 (Widgets)
* **Тесты:** Boost.Test (header-only)
* **Сборка:** CMake

## Математическая модель
В основе лежит задача трех тел (Земля, Луна, корабль) и интегрирование методом Рунге-Кутты 4-го порядка.

**Сравнение симуляции с реальными данными NASA:**
Особенностью проекта является параллельная отрисовка двух траекторий. Красный Орион - это моя симуляция, а белый - реальные данные NASA Horizons. Так можно наглядно сравнить, где моя идеальная физика расходится с их сложными моделями.

Погрешность набегает из-за того, что я не учитываю гравитацию Солнца, давление света и мелкие корректировки орбиты двигателями во время полета.

> **Примечание:** Я начинаю симуляцию не прямо со старта, а когда маршевые двигатели уже отработали. Первый кусок полета просто берется из данных NASA (потому что у меня нет их точных данных о тяге). Движок сам находит этот момент по пику скорости и дальше уже считает физику сам.

В окне выводится время полета, скорости обоих Орионов, а еще можно включать/отключать показ реальной и симулированной траектории галочками.

## Как запустить проект
Вы можете либо воспользоваться готовым скомпилированным релизом, либо собрать проект вручную из исходного кода.

### Вариант 1: Быстрый запуск
Просто скачайте готовый архив из **Releases**, распакуйте и запустите `artemis_sim.exe` (или аналог для вашей ОС). CMake и компиляторы для этого не нужны.

### Вариант 2: Сборка из исходников
Если хотите собрать сами, понадобятся компилятор C++, CMake и установленный Qt5. А для сборки тестов нужен еще распакованный Boost.

Откройте терминал в папке с проектом:

```bash
# Конфигурируем проект (путь до Boost нужен только если хотите собрать тесты)
cmake -B build -DBOOST_INCLUDE_DIR="ваш/путь/к/boost"

# Собираем
cmake --build build

# Запускаем сам симулятор (на Windows)
.\build\Debug\artemis_sim.exe

# Запускаем симулятор (на Linux/macOS)
./build/artemis_sim

# Запуск тестов
.\build\Debug\artemis_tests.exe
```

## Источники данных
Оригинальные эфемериды для Луны и Ориона взял из открытой базы **NASA JPL Horizons**. Они лежат в папке `data/` в форматах `.txt`.
